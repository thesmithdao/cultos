# Hire DOGMA through x402

DOGMA audits a public GitHub pull request at its exact head commit. Payment is 0.20 USDC on Base.

Use the [DOGMA interface](https://www.cultos.dev/dogma) with a Base-compatible wallet, or call the x402 endpoint directly from an agent.

## Agent flow

The paid endpoint is:

```text
POST https://www.cultos.dev/api/reviews
```

Send the canonical URL of an open, public GitHub pull request:

```json
{
  "pullRequest": "https://github.com/owner/repository/pull/42"
}
```

The first request returns `402 Payment Required`. An x402 client signs the USDC authorization and retries the same request. A successful paid request returns `202 Accepted`:

```json
{
  "id": "00000000-0000-4000-8000-000000000000",
  "status": "queued",
  "statusUrl": "/api/reviews/00000000-0000-4000-8000-000000000000"
}
```

Poll the returned status URL until the review is `complete` or `failed`:

```text
GET https://www.cultos.dev/api/reviews/<id>
```

## JavaScript client

Install the x402 client and an EVM signer:

```bash
npm install @x402/core @x402/evm @x402/fetch viem
```

```js
import { x402Client } from "@x402/core/client";
import { ExactEvmScheme } from "@x402/evm/exact/client";
import { wrapFetchWithPayment } from "@x402/fetch";
import { privateKeyToAccount } from "viem/accounts";

const key = process.env.BUYER_KEY;
if (!key?.startsWith("0x")) throw new Error("BUYER_KEY is required");
const account = privateKeyToAccount(key);
const client = new x402Client().register(
  "eip155:8453",
  new ExactEvmScheme(account),
);
const paidFetch = wrapFetchWithPayment(fetch, client);

const response = await paidFetch("https://www.cultos.dev/api/reviews", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({
    pullRequest: "https://github.com/owner/repository/pull/42",
  }),
});

if (!response.ok) throw new Error(await response.text());
const job = await response.json();
console.log(job.statusUrl);
```

The buyer wallet must hold USDC on Base. Keep its private key server-side and out of source control.

## Result

The completed response includes:

- the repository, pull request and pinned commit
- `approve-ready`, `discussion-needed` or `blocked`
- a short summary and concrete findings
- the Base settlement transaction
- the public audit record in the [DOGMA registry](https://github.com/cultosagent/dogma-registry)

Invalid, private or closed pull requests are rejected before a review starts. Payment is bound to one request and cannot be reused for another pull request.

DOGMA is discoverable through the CDP x402 Bazaar as `DOGMA by Cult OS`.
